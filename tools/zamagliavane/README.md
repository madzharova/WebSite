# Замъгляване на лица

Подготвя снимки с ученици за публичния сайт: открива лицата и ги замъглява меко,
останалата снимка остава непокътната. Премахва и скритите данни от снимката (GPS, дата, телефон).

## Употреба

Обикновено го пуска Claude. Ако искате сами (нужен е Python 3):

```bash
pip install ai-edge-litert pillow numpy opencv-python-headless
python3 blur_faces.py ПАПКА_СЪС_СНИМКИ ПАПКА_ЗА_РЕЗУЛТАТА --preview
```

В резултата:
- `*.jpg` – замъглено копие в пълен размер (архив);
- `*.webp` – копие за сайта (до 1600 px);
- `_proverka/` – оригиналът с червени рамки около откритите лица → **прегледайте го**;
- `_otchet.txt` – колко лица са открити във всяка снимка.

## Поправки на ръка – `manual.json` в папката със снимките

```json
{
  "IMG_4702.jpg": { "add": [[905, 230, 40, 50]] },
  "znamenosci.jpg": { "keep": [[210, 430, 70, 70]] },
  "klasna-staia.jpg": { "skip": true }
}
```
- `add` – допълнително замъгляване (x, y, ширина, височина в пиксели от оригинала), ако някое лице е пропуснато;
- `keep` – област, която остава ясна (например вашето лице);
- `skip` – снимката се копира без замъгляване (напр. няма хора).

Оригиналите никога не се променят.
